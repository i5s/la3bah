# بطولة الشرقية — روميكوب

صفحة حجز لبطولة روميكوب: 16 لاعب → 4 مجموعات → نهائي → بطل.

**هذه نسخة Static (localStorage)** — تعمل بدون سيرفر، البيانات في متصفح المستخدم فقط (مناسبة للاستخدام ليوم واحد).

## محتويات الرفع
- `index.html` — الصفحة كاملة (حجز + تحقق + مجموعات + نظام البطولة)
- `rummikub-logo.png` — اللوقو

## الرفع على Render (Static Site)
1. ارفع هذا المجلد إلى مستودع GitHub
2. في Render → New → **Static Site**
3. اربط المستودع
4. Build Command: (فارغ، اتركه)
5. Publish Directory: `.`
6. Deploy

الصفحة ستُعرض مباشرة على رابط `https://xxx.onrender.com`
