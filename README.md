# بطولة الشرقية — روميكوب

صفحة حجز لبطولة روميكوب: 16 لاعب → 4 مجموعات → نهائي → بطل.

**نسخة متصلة بقاعدة بيانات Supabase** — البيانات محفوظة في السحابة، فيستطيع اللاعبون التسجيل من أي جهاز، ويمكن للمنظم مشاهدة/تعديل الحجوزات من لوحة التحكم.

## المحتويات
- `index.html` — الصفحة العامة: حجز + تحقق + المجموعات + حالة البطولة (تحديث لحظي)
- `admin.html` — لوحة التحكم: عرض كل اللاعبين (اسم/جوال/مجموعة/رقم) مع حذف، إعادة فتح التسجيل، تفريغ الكل
- `config.js` — بيانات Supabase (URL + مفتاح) — عدّلها هنا فقط عند الحاجة
- `app.js` — منطق الاتصال بقاعدة البيانات + واجهة المتجذّر
- `rummikub-logo.png` — اللوقو

## الرفع على Render (Static Site)
1. ارفع هذا المجلد إلى مستودع GitHub
2. في Render → New → **Static Site**
3. اربط المستودع
4. Build Command: (فارغ، اتركه)
5. Publish Directory: `.`
6. Deploy

- الصفحة العامة: `https://xxx.onrender.com/`
- لوحة التحكم: `https://xxx.onrender.com/admin.html`

## ملاحظات أمان (مهم)
- هذه الأداة مخصصة للاستخدام **المؤقت** خلال يوم البطولة. بعد انتهاء الحدث احذف البيانات.
- لوحة التحكم مفتوحة بدون كلمة مرور (يكفي معرفة الرابط) — تجنب نشره علناً ما دام التسجيل جارٍ، واحذف بيانات اللاعبين وحاورهم فور انتهاء البطولة.
